Entry for the [Funniest Time Machine Warning Label](https://make.fun/c/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151?ref=h379tqrk) bounty on make.fun.

`main.py` writes one warning label (112 characters) to `/output/entry.txt`:

> WARNING: If you meet your grandfather, say nothing of the future. He will put his life savings into Blockbuster.

Run it with:

```sh
python3 main.py
```

It honours `MAKEFUN_OUTPUT_DIR` (default `/output`), writes the file
directly with `open("wb")`, and sets mode `0644`. Standard library only.
